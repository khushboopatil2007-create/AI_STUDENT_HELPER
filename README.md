# 🎓 AI Student Help Expert System

> An AI-based student assistance system that provides study recommendations using **rule-based reasoning and knowledge representation**.

---

## 🌟 Overview

The **AI Student Help Expert System** is a simple and user-friendly application designed to help students identify what concepts they should focus on when facing difficulties in a particular subject.

The system takes the student's **name, subject, and problem** as input and uses a predefined knowledge base to generate a suitable study recommendation.

The application is built using **Python** and **Streamlit**.

---

## 🎯 Objectives

- 🤖 Develop a simple AI-based student assistance system.
- 🧠 Apply **knowledge representation and rule-based reasoning**.
- 📚 Provide useful study recommendations based on student input.
- 💻 Apply Artificial Intelligence concepts to a practical problem.
- 📝 Maintain a history of student queries during the application session.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| 👤 Student Input | Accepts the student's name |
| 📖 Subject Selection | Allows students to select a subject |
| 🔍 Problem Selection | Allows students to select their area of difficulty |
| 🤖 AI Recommendation | Generates a recommendation using predefined rules |
| 📝 Query History | Displays previous queries during the session |
| 🎨 Simple Interface | Easy-to-use Streamlit web interface |

---

## 🧠 AI Approach

The project uses a **Rule-Based AI approach**.

The system contains a knowledge base consisting of predefined rules.

Subject + Problem
       ↓
