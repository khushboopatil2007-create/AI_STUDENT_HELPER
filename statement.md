# Problem Statement

## Project Title
AI Student Help Expert System

## Problem Statement

Students often face difficulty identifying what concepts they should study when they have problems in a particular subject. They may know that they are struggling but may not know which topic to focus on.

The AI Student Help Expert System provides simple study recommendations based on the student's selected subject and problem.

## Project Objective

The main objectives of this project are:

- To develop a simple AI-based student assistance system.
- To use knowledge representation and rule-based reasoning.
- To provide study recommendations based on student input.
- To demonstrate the application of AI concepts to a real-world problem.
- To maintain a history of student queries.

## Scope

The system focuses on providing basic study recommendations for selected programming, Artificial Intelligence, and Machine Learning topics.

The current system covers:

- Python
- C++
- Artificial Intelligence
- Machine Learning

## Target Users

The system is intended for students who need simple guidance about which concepts to study.

## High-Level Features

1. Student information input
2. Subject and problem selection
3. Rule-based recommendation
4. Student query history
5. Simple web-based interface using Streamlit

## AI Technique Used

The system uses a rule-based approach.

The knowledge base contains predefined rules connecting a subject and a problem with an appropriate study recommendation.

## Expected Outcome

The system should accept student input and generate a relevant study recommendation. It should also record the student's query during the application session.
